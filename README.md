# PartPilot

PartPilot adalah sistem pencocokan work order suku cadang yang dirancang untuk mempermudah identifikasi, verifikasi ketersediaan, dan rekomendasi suku cadang pengganti secara akurat berdasarkan spesifikasi teknis dan riwayat servis peralatan.

## Rencana Struktur Direktori

```
partpilot/
├── app/          # Logika aplikasi dan API service
├── db/           # Skema database, migrasi, dan seed data
├── docs/         # Dokumentasi teknis dan panduan operasional
└── tests/        # Unit test dan integration test
```

## Setup & Instalasi

Petunjuk instalasi dan konfigurasi lingkungan kerja akan diperbarui seiring berjalannya pengembangan modul backend.
